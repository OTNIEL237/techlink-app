                         🌊 FLUX DE REQUÊTE (AVANT vs APRÈS)
═════════════════════════════════════════════════════════════════════════════════

ANCIEN FLUX (NotchPay + 5% Commission):
─────────────────────────────────────
1. Client choisit technician et paie 20000 FCFA
2. Mobile envoie: POST /notchpay/callback
3. NotchPay retient 5% = 1000 FCFA
4. Backend calcule: technician_amount = 20000 * 0.95 = 19000 FCFA
5. Technician wallet += 19000 FCFA
6. TechLink reçoit: 1000 FCFA
7. Pas d'abonnement, accès illimité


NOUVEAU FLUX (CamerPay + 0% Commission + Subscription):
────────────────────────────────────────────────────
1. Technicien s'inscrit
2. NOUVEAU: Écran de sélection d'abonnement apparaît
   ├─ Option A: Essai gratuit 30 jours → trial_end_date = now + 30j
   ├─ Option B: Abonnement 2000 FCFA/mois → CamerPay WebView
   └─ Option C: Abonnement 20000 FCFA/an → CamerPay WebView

3. Client choisit technician (avec subscription active) et paie 20000 FCFA
4. Mobile envoie: POST /api/payments/initialize
5. Backend envoie: POST à CamerPay
6. CamerPay retient 0% (commission_percentage: 0)
7. Backend calcule: technician_amount = 20000 FCFA (100%)
8. Technician wallet += 20000 FCFA ✅ (plus haut!)
9. TechLink reçoit: 2000 FCFA (subscription fee) + 20000 FCFA/an (annuel)
10. Technician a accès SEULEMENT s'il a subscription/trial active

                    🔐 SÉCURITÉ - VALIDATION DE SIGNATURE
═════════════════════════════════════════════════════════════════════════════════

AVANT:
- Webhooks NotchPay: Validation simple (juste comparer le statut)

APRÈS (CamerPay):
- Webhooks CamerPay: Validation HMAC-SHA256
  ├─ Recevez header: X-CamerPay-Signature
  ├─ Validez signature avec CAMERPAY_WEBHOOK_SECRET
  ├─ Rejettez si signature invalide (403 Forbidden)
  └─ Résultat: Plus sûr, pas de spoofing possible
